# Оформление игры как HR Feedback

Запрос: «сделай дизайн как в hr feedback». Найден источник владельца: Kseniya0512/hr-feedback-survey, ветка hr-feedback-app, commit 62360e3f26ba0729076047caac51037f820d246d. Прочитаны styles.css/index.html, просмотрены работающие главный экран и анкета. Ветка main содержит только README, поэтому использован фактический интерфейс приложения из hr-feedback-app.

Переносим визуальный язык: белый фон, фиолетовый #8113FF / hover #6810CD, текст #25232E, вторичный #777480, границы #e9e7ee, лавандовые поверхности #f5efff. Системный Inter-stack без загрузки внешних шрифтов. Шапка «РТК ИТ / Люди и изменения», верхние вкладки, светлая боковая навигация с фиолетовым активным шагом, карточки с радиусом 22px, кнопки 11px, крупные заголовки, тонкие границы, увеличенные отступы. Вводная получает иллюстрацию с фиолетовым диалогом и орбитами по мотивам HR Feedback.

Общая тема для серверной и автономной версий. Помощь ЦЭИ/командные панели ниже основного задания с прямой кнопкой из шапки. Все игровые поля, сохранения, таймер, вопросы, критерии и экспорт сохраняют поведение и ключи. Адаптивность до 320px, видимый keyboard focus, печать/PDF и полностью автономный HTML сохраняются. Цвета проверки ошибок и корректных ответов остаются семантическими.

Проверка: существующие unit/API и browser-сценарии, обе сборки; визуальное сравнение с источником и проверка геометрии на 320/390/768/1024/1440px. Новые тесты констант цветов не создаются для этого обратимого изменения оформления. После проверки пересобрать docs/index.html, commit/push main и проверить успешную публикацию Pages.
