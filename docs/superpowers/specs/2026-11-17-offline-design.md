# Автономная игра без подключений

Пользователь разрешил упростить запуск до HTML-страницы, чтобы пройти игру без сервера, либо получить готовую ссылку. Добавляем самостоятельную версию, сохраняя существующую серверную игру.

Один самодостаточный HTML-файл в docs/index.html: React, CSS, иконки и задания встроены, внешних шрифтов, API и CDN нет. Его можно скачать и открыть двойным щелчком или разместить в GitHub Pages из ветки main, каталога /docs. Задания, проверки, методология и генератор плана переиспользуются из готовой версии, а не дублируются.

Локальные 3 рабочих листа команд, общий таймер 30 минут, выбор команды/переименование, навигация 9 экранов, исправление ответов, экспорт плана Markdown/JSON, печать/PDF. Автосохранение в текущем браузере; резервная копия всех ответов в JSON с валидируемым импортом. Это работа на одном экране либо независимое прохождение на разных устройствах; удалённая синхронизация и серверные роли не имитируются. Ограничение явно видно в интерфейсе.

Альтернативы: существующий сервер сохраняет полноценную совместную работу, но требует хостинга; внешняя база требует дополнительной настройки, от которой пользователь отказался. Поэтому автономный файл выбран как основной простой способ запуска.

GitHub API и адрес github.io сейчас блокируются сетевой политикой облачной среды (HTTP CONNECT 403); git push доступен. Реализуем готовый файл и workflow публикации, проверяем доступность Pages при появлении разрешённого доступа. Не выдаём предполагаемый URL за опубликованный.
