# Проверка реализации — 17 ноября 2026

Проверки выполнены в облачной среде на Node.js 24.22.1 и системном Chromium.

| Проверка | Результат |
| --- | --- |
| `npm ci --cache /tmp/workshop-npm-cache --no-audit --no-fund` | Повторная установка по lockfile прошла |
| `npm test` | 13 тестов, все прошли; 0 пропущенных |
| `npm run build` | TypeScript + Vite production build прошли |
| `npm run test:e2e` | 4 сценария, все прошли |
| `npm audit --omit=dev` | 0 уязвимостей |
| Docker | Образ собран; production smoke и перезапуск с сохранённым томом прошли |

Что проверено функционально:

- Создание комнаты на 2/3 команды; отдельные роли и отсутствие чужих ответов/приглашений в API участника.
- Капитан, участник, куратор-помощник, выдача права записи; комментарии и отказ в недопустимых записях.
- Восемь критериев и порог 2, уточнение критериев 5/6/8, сумма тайминга 30 минут.
- Параллельная запись разных полей и отказ 409 для устаревшей версии одного поля.
- Полное прохождение семи заданий с исправлением ошибочных решений и заполнением всех 20 разделов плана.
- Реальные ответы, включая альтернативный маршрут, сохраняются в плане и экспорте; пропуски не заменяются идеальными ответами.
- Синхронизация капитана и участника в разных браузерных контекстах, перезагрузка страницы, Markdown и JSON.
- Обрыв сети и конфликт не уничтожают черновик открытой вкладки; явное повторное сохранение работает.
- Мобильные страницы входа и финального плана без горизонтального скролла.
- Серверный таймер, пауза, автоматическое завершение по сроку; ответы сохраняются.
- SQLite восстанавливает ответы, сеансы, комментарии и права после рестарта API; Docker восстанавливает ответ, сессию и работающий таймер после перезапуска контейнера.
- SSE прекращает отдавать снимки после logout и истечения сессии.

Независимое ревью выполнено другим агентом. Все три найденные проблемы исправлены с воспроизведением тестами. Docker первоначально потребовал доверенный CA облачной среды: использован BuildKit secret во временном Dockerfile; проверка TLS и проверки пакетов сохранены.

Не проверялись: реальная публикация на внешнем домене, сертификат и настройки внешнего reverse proxy, GitHub Actions до push, корпоративный SSO и проведение с двадцатью людьми ровно за тридцать минут. Эти пункты не выдаются за пройденные проверки.
